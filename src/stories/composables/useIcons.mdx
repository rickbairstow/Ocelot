# useIcons

Every icon from the installed [Tabler Icons](https://tabler.io/icons) Vue package is registered automatically, including brand and filled icons. Use the Tabler export name without the `Icon` prefix. No per-icon imports or application setup are needed.

## Exports

| Export | Description |
| --- | --- |
| `availableIcons` | Registry of icon names to Vue components, including the complete installed Tabler catalogue |
| `availableSizes` | Size names mapped to pixels |
| `registerIcons` | Register custom icons or override names before rendering |
| `IconName` | Type containing all installed Tabler short names and OUI aliases |
| `IconProp` | An icon name or Vue component; custom string names are also accepted |
| `IconSize` | A supported size name |

## Usage

```vue
<Icon icon="BrandGithub" size="lg" />
<Icon icon="StarFilled" />
<Button icon="World">Visit website</Button>
```

The same names work in every OUI component with an icon prop. Existing names remain supported, including `123`, `ChevronUpDown`, `Collapse`, `Expand`, `MoreHorizontal` and `MoreVertical`.

## Custom icons

Use `registerIcons()` for your own icons, rather than for icons already provided by Tabler:

```ts
import { registerIcons } from 'ocelot-ui'
import CompanyLogo from './CompanyLogo.vue'

registerIcons({ CompanyLogo })
```

```vue
<Icon icon="CompanyLogo" />
```

Alternatively, pass a Vue component directly as `:icon="CompanyLogo"`. Registration can override an existing name and should happen before components render. The registry is a plain module-scoped object, not a reactive store.

## Bundle tradeoff

All icons are bundled locally and available synchronously. This adds the full catalogue to the bundle compared with importing a small curated set. No runtime CDN requests or consumer Tabler imports are required. The available catalogue tracks the version of `@tabler/icons-vue` installed with OUI.
