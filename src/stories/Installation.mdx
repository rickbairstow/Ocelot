# Installation

## Prerequisites

- Vue 3.5+
- Tailwind CSS v4

Use the Node.js version supported by your application's build tools. The Node.js version in this repository's `.nvmrc` is for developing and building OUI, not a requirement for consuming the published package.

## Install

```bash
npm install ocelot-ui
```

Optional feature dependencies:

```bash
# Table
npm install @tanstack/vue-table@^9.3.1

# LightboxImage / Gallery with lightbox enabled
npm install photoswipe@^5.4.4

# Video
npm install plyr@^3.8.5

# QrCode
npm install qrcode@^1.5.4
```

Install only the packages for the features you use. Gallery uses the same PhotoSwipe dependency as LightboxImage; set `:lightbox="false"` for a passive thumbnail list without it. Hero, Footer, CallToAction, HelpText and ErrorText need no additional feature dependencies.

OUI warns in development when an optional feature dependency is missing. The lightbox dependency is loaded when opening the viewer.

## Setup

### 1. Configure Tailwind

Import the OUI Tailwind plugin in your main CSS file. It adds the `@source` scan for OUI classes, design tokens, and the dark mode variant bridge:

```css
/* your main CSS file */
@import "tailwindcss";
@import "ocelot-ui/tailwind.css";
@custom-variant dark (&:where(.dark, .dark *));
```

### 2. Import Vue transition styles

```js
// main.js / main.ts
import 'ocelot-ui/style.css'
```

### 3. Use components

Import the components you need:

```js
import { Button, Dialog, Toast } from 'ocelot-ui'
```

Or register globally:

```js
// main.js / main.ts
import { createApp } from 'vue'
import { Button, Input, Dialog } from 'ocelot-ui'
import 'ocelot-ui/style.css'
import App from './App.vue'

const app = createApp(App)
app.component('Button', Button)
app.component('Input', Input)
app.component('Dialog', Dialog)
app.mount('#app')
```

### Table notes

`Table` depends on `@tanstack/vue-table` version 9 and includes a built-in settings menu for density, column visibility, and pinning. Consumers upgrading from version 8 must update this peer dependency. Typed column helpers now use `createColumnHelper<StockFeatures, YourRow>()`; import both from `@tanstack/vue-table`. On smaller screens, you can keep the table scrollable or switch to stacked cards with `mobileLayout="card"`.

### CommandPalette notes

`CommandPalette` teleports to `#portal-target`. Register commands with `useCommandPalette()`, then mount the component once near the app root so it can respond to `Ctrl+K` / `Cmd+K`.

## Icons

OUI includes every icon from its installed [Tabler Icons](https://tabler.io/icons) catalogue, including brand icons and filled variants. No Tabler imports or registration are required. Use the export name without its `Icon` prefix:

```vue
<Icon icon="BrandGithub" />
<Icon icon="StarFilled" />
<Button icon="BrandLinkedin">LinkedIn</Button>
```

`registerIcons()` is still available for custom icons and overrides, and icon props still accept Vue components directly. The full catalogue is bundled locally; it does not fetch icons from a CDN. This increases bundle size compared with a small curated set.

---

## Dark mode

Dark mode is toggled via the `.dark` class on a parent element (typically `<html>`):

```html
<html class="dark">
  ...
</html>
```

---

## Overlay portal target

Dialog, CommandPalette and Toast render outside the component tree using Vue's Teleport. They create `#portal-target` on the client if it is missing. You can also supply it in your `index.html`:

```html
<div id="app"></div>
<div id="portal-target"></div>
```

To use a different shared target, configure it before mounting the application:

```js
import { configureTeleportTarget } from 'ocelot-ui'

configureTeleportTarget('#overlays')
```

Keep the target outside containers that clip content, and apply the `.dark` class to `<html>` when overlays need to share the page theme.

## Design tokens

Override OUI's CSS custom properties to customise appearance without a Tailwind rebuild:

```css
:root {
    --oui-radius-lg: 0.75rem;
}
```

See `ocelot-ui/tailwind.css` for the full list of available tokens.
