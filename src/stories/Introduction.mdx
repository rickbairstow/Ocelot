# Ocelot UI

Ocelot UI (OUI) is a Vue 3 component library built with Tailwind CSS v4. It provides accessible, themeable components optimised for modern web applications.

Start with <a href="./?path=/docs/getting-started-installation--docs" target="_top">Installation</a> for dependencies and CSS setup. Each component page includes its props, slots and focused examples; **Default** shows the base component with its required content and accessible naming.

## Choosing components

- **Forms:** use Input for native input types, Select for ordinary choices, and Combobox for searchable single or multiple selection. FormField connects labels, help and errors; HelpText and ErrorText are available for custom layouts. The consumer owns validation, fetching and submission. See the <a href="./?path=/docs/components-inputs-overview--docs" target="_top">Inputs guide</a>.
- **Pages:** Hero introduces a page, CallToAction presents a next step, and Footer holds closing content and navigation. Supply your own copy, media, buttons and links through their props and slots.
- **Images:** Image handles individual images; LightboxImage adds a viewer. Gallery arranges a responsive thumbnail collection with optional captions and a shared viewer for that collection.

The **Patterns** group contains composed examples: <a href="./?path=/docs/patterns-marketing-page--docs" target="_top">Marketing Page</a>, <a href="./?path=/docs/patterns-forms--docs" target="_top">Forms</a>, product screens and RTL layouts. Use these as starting points for your own pages.
